## Why I built FilterWorkbench

FilterWorkbench is not intended to replace the Gramps Filter Editor. It is a
side-by-side solution for the way I prefer to build, organize and test filters.

The Gramps Filter Editor also provides functionality that I use and that is not
included in FilterWorkbench.

My main reasons for building FilterWorkbench were:

1. I wanted to avoid filling the normal Gramps filter lists with many helper
   filters that are used only as building blocks for a single main filter.
   These helper filters would otherwise also appear in other filter lists
   throughout Gramps.

2. I wanted the purpose of individual rules and filters to be easier to see,
   and I wanted to be able to test them directly against the People view to see
   which people match the selected rule, helper filter or complete main filter.

3. I wanted a separate list of the filter rules I use most often, which I call
   **Favorites**.

4. I still have the idea of making the process of building filters even simpler.
   Perhaps one day I will find the right approach.
